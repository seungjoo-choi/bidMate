# 추출 정답셋 (2026-11-03, 80건)

나라장터 최근 12개월(2025-11 ~ 2026-10) 용역 공고 80건을 무작위로 뽑아 16개 검토 항목의 정답을 만든 것입니다. 룰을 고친 뒤 정확도가 실제로 좋아졌는지 숫자로 확인하는 데 씁니다.

- 계약 방식: 협상 31, 소액수의 25, 적격심사 13, 최저가 6, 수의시담 4, 기타 1
- 정답은 규칙 결과를 보지 않고 문서만 읽어 만들었습니다. 작성 기준은 [label-guide.md](label-guide.md)

## 파일
| 경로 | 내용 |
|---|---|
| `data/notices.json` | 나라장터 API 공고 원본(담당자 이름과 연락처 필드 제거) |
| `data/gold/<공고번호>.json` | 항목별 정답. kind는 value(값 있음), na(해당 없음), absent(문서에 없음), multi(값 여러 개) |
| `dl.mjs` | 첨부 원본 다운로드(키 불필요, 약 180MB, `files/`에 저장) |
| `measure.test.ts` | 앱의 추출 단계(runExtractStep)와 검토 판정(leafReviewState)을 그대로 돌려 `out/`에 결과 저장 |
| `compare.mjs` | 정답과 결과 비교, 항목별 표 출력 |

`files/`와 `out/`은 git에서 제외합니다.

## 실행
```
node scripts/gold/dl.mjs                                         # 처음 한 번
npx vitest run --config scripts/gold/vitest.config.mjs           # OUT=이름.json 으로 결과 파일 이름 지정
node scripts/gold/compare.mjs [이름.json]
```

## 읽는 법
- 정답: 룰 결과가 정답과 같음. 정답(묶음)은 그룹 충족(대외신인도/경영상태)
- 놓침: 문서에 값이 있는데 룰이 못 찾음
- 해당없음 못가림: 정답은 해당 없음인데 룰이 확인 필요로 둠
- 오탐/틀림(확정): 룰이 확정한 값이 틀림
- 제안서 제출기간, 제안서 평가일자는 앱에서 나라장터 상세 화면 값으로 채워지는데 이 측정에는 상세 화면이 없어 낮게 나옵니다. 비교에서 제외하고 보세요.
- 정답 일부는 confidence가 low/medium입니다. 비교에서 다르게 나오면 원문(`files/<공고번호>/source/text`)으로 다시 확인하세요.
