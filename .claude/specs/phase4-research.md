## 형식별 결과
- **HWP 5.1 바이너리**(3개 모두 compressed, 암호/배포용 아님)
  - `hwp.js@0.0.3`: f6만 성공. f1/f3은 `invalid stored block lengths`(압축 해제 실패)로 예외 → 사용 불가.
  - 직접 작성 최소 추출기(약 60줄): `cfb`로 OLE 읽기 → `BodyText/SectionN`을 raw inflate → 레코드(헤더 32bit: tag 10bit, level 10bit, size 12bit, 0xFFF면 다음 4바이트) 순회.
    - PARA_TEXT(tag 67) UTF-16LE. 제어문자: 1,2,3,11,12,14~18,21~23은 확장 컨트롤로 16바이트(8 WCHAR) 차지, 9는 탭(16바이트), 10/13은 줄바꿈.
    - CTRL_HEADER(71) ctrlId ' lbt'(=tbl) = 표 시작, LIST_HEADER(72)의 offset 8/10 = 셀 열/행 주소.
    - 결과: f1 1439줄 7ms, f3 10142줄 21ms, f6 43줄 3ms. 표 셀의 행/열 위치 유지.
    - 미확인: 병합 셀 rowspan/colspan, 표 안의 표, 레벨로 셀 소속 판정(검증 스크립트는 단순 순서 기반).
  - Node `zlib.inflateRawSync` 사용. 브라우저에서는 `DecompressionStream('deflate-raw')` 또는 pako(번들) 필요.
- **PDF**: `pdfjs-dist@4` legacy, 25p 35,182자 0.23s. 단어 사이 공백 누락/`\u0000` 섞임 → 공백/NUL 제거 정규화 후 검색해야 매칭됨(정규화 후 "차등점수제" 매칭 확인). 한글 CMap 필요(cMapUrl 번들).
