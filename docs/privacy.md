# 비드메이트 개인정보처리방침

시행일: 2026년 11월 3일

비드메이트(이하 "확장 프로그램")는 나라장터 입찰 공고를 수집·정리하고 입찰 관련 메일 작성을 돕는 Chrome 확장 프로그램입니다. 이 방침은 확장 프로그램이 어떤 정보를 다루고, 어디에 저장하며, 어디로 전송하는지 설명합니다.

## 1. 기본 원칙

- 확장 프로그램은 **개발자가 운영하는 서버가 없습니다.** 사용자의 정보를 개발자에게 전송하거나 수집하지 않습니다.
- 모든 데이터는 **사용자의 브라우저 안에만** 저장됩니다.
- 사용 통계, 광고, 추적 도구를 사용하지 않습니다.
- 사용자 데이터를 판매하거나, 확장 프로그램의 목적과 관계없는 용도로 사용하거나, 신용 평가·대출 심사에 사용하지 않습니다.

## 2. 다루는 정보와 저장 위치

| 정보 | 용도 | 저장 위치 |
|---|---|---|
| 입찰 공고 내용과 첨부파일 | 공고 정리, 검색, 자격 요건·평가 항목 확인 | 사용자 브라우저 |
| 사용자 설정, 관심 공고 목록 | 확장 프로그램 동작 | 사용자 브라우저 |
| 공공데이터포털 인증키, AI 서비스 API 키 | 각 서비스 호출 | 사용자 브라우저 |
| 네이버웍스 연락처(이름, 이메일 주소) | 메일 받는 사람 입력 보조 | 사용자 브라우저 |
| 사용자가 작성하는 메일 내용 | 메일 작성 화면에 입력 | 사용자 브라우저 |

## 3. 외부 서비스로 전송되는 경우

확장 프로그램은 사용자가 기능을 사용할 때에만 아래 서비스와 직접 통신합니다. 이 통신은 사용자의 브라우저와 해당 서비스 사이에서만 이루어지며 개발자를 거치지 않습니다.

- **조달청 공공데이터포털(apis.data.go.kr), 나라장터(www.g2b.go.kr)**: 입찰 공고와 개찰 결과를 조회합니다.
- **AI 서비스(OpenAI, Anthropic, Google Gemini 중 사용자가 선택한 곳)**: 사용자가 AI 검토 기능을 실행하면 해당 공고의 내용이 사용자가 선택한 AI 서비스로 전송됩니다. 전송된 정보는 해당 서비스의 개인정보처리방침을 따릅니다. AI 기능은 선택 사항이며, 사용자가 API 키를 입력하고 사이트 접근을 허용해야만 동작합니다.
- **메일 서비스(네이버웍스, Gmail)**: 사용자가 메일 작성을 요청하면 사용자가 연 메일 작성 화면에 내용을 입력합니다. 확장 프로그램이 메일을 직접 보내지는 않으며, 보내기는 사용자가 직접 합니다.

## 4. 권한 사용

확장 프로그램은 설치할 때 나라장터와 공공데이터포털에만 접근 권한을 요청합니다. AI 서비스나 메일 서비스 같은 다른 사이트는 사용자가 해당 기능을 켤 때 사이트별로 따로 허용을 받습니다. 클립보드 읽기 권한도 사용자가 직접 허용한 경우에만 사용합니다.

## 5. 데이터 삭제

확장 프로그램을 삭제하면 브라우저에 저장된 데이터(입력한 인증키와 API 키 포함)가 모두 함께 삭제됩니다.
