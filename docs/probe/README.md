# probe 리포트

BidMate 사이드 패널의 [진단] 탭으로 네이버웍스 메일쓰기 화면의 DOM을 기록합니다. 읽기·관찰 전용이며 클릭이나 키 입력을 하지 않습니다.

## 녹화 시나리오
1. 메일쓰기 열기
2. 받는사람 1명 입력·확정
3. 참조 열기 → 1명 입력
4. 제목 입력
5. 본문 한 줄 입력
6. 작은 파일 1개 첨부 → 업로드 완료 대기
7. (선택) 임시저장
8. 녹화 정지·저장

주의: **보내기 버튼은 누르지 마세요.**

## 리포트 보관
[녹화 정지·저장]이나 [스냅샷]으로 내려받은 `bidmate-probe-<host>-<yyyyMMdd-HHmmss>.json`을 이 폴더에 넣어 주세요. 이메일 로컬파트는 `***`로 마스킹되고 입력값(value)은 수집하지 않지만, 넣기 전에 한 번 확인하세요.
